## Intent

Three short, silent, seamlessly looping motion videos that replace the three animated
README images of the AshPack repo (docs/ashpack.svg, docs/ashpack-status.svg,
docs/ashpack-skins.svg). Professional typography and smooth animation; they must show
the mods as they are now.

1. **ashpack** — "One drawer for all your mods": a tab per mod in a side drawer, and one
   chip strip above the prompt.
2. **ashpack-status** — "See what Claude is doing, and keep it": status chips by the
   prompt, compact mode's working popup (running step, wave, Tasks card; no call cards
   any more), and the Activity page (turn card, its calls, session tiles, timeline,
   turn list).
3. **ashpack-skins** — "One pick recolours the whole conversation": the same turn across
   several skins, then code and table cards, then charts.

## Customizations

- Each scene gets a proven motion treatment (blueprints / named rules), not improvised
  movement.
- Clean scene handoffs (cuts, quick wipes); no heavy shader transitions.
- One storyboard sheet covers all three videos; reviewed together at each pass.
- Output: animated WebP, 880 px wide, looping, replacing the three README SVGs.

## Notes

- Look left to the workflow's design step.
- No narration, no music: README images are silent.
- Content is the real UI: the mods' own SVG output where it exists (Activity cards,
  code/table cards, charts), the rest rebuilt from the mods' code. No stock media, no
  invented features.
- The hero banner (docs/hero.svg) and title (docs/title.svg) stay as they are.
- On-screen text must still read at 880 px wide: large and sparse.
